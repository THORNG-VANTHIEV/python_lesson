# រៀន Python ពីសូន្យ

គេហទំព័រមេរៀន Python ជាភាសាខ្មែរ សម្រាប់អ្នកចាប់ផ្តើម។ មានមេរៀន ១២ លំហាត់ ឧទាហរណ៍កូដ គម្រោងបញ្ចប់ និងការតាមដានវឌ្ឍនភាព។

## របៀបប្រើ

បើក `index.html` ក្នុង browser។ មិនចាំបាច់ដំឡើង package ឬ build ទេ។ អាចប្រើ navigation menu ដើម្បីជ្រើសរើសមេរៀន ហើយធីក «បានរៀនចប់» ដើម្បីរក្សាវឌ្ឍនភាពក្នុង browser។

ឯកសារសំខាន់ៗ៖

- `index.html` — មាតិកាវគ្គសិក្សា
- `css/` — រចនាបថទំព័រ
- `js/` — navigation, drawer, progress និង copy code
- `archive/` — កំណែ single-file ចាស់

Font និង syntax highlighting ត្រូវការអ៊ីនធឺណិត។ មាតិកាមេរៀននៅតែអានបានពេលគ្មានអ៊ីនធឺណិត។
